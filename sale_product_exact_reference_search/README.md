# Sale Product Exact Reference Search

Prioritizes an exact displayed or internal reference match in the product
autocomplete on sales order lines. As a result, pressing Enter after typing a
complete reference selects that product instead of an earlier partial match.

Displayed references are also supported when another module supplies the code
shown between brackets, for example a customer-specific product reference.

The behavior is scoped to product searches opened from sales orders and does
not alter product searches in other applications.
